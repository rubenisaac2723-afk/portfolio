## 🛠️ Tech Stack & Architecture

### **Frontend & Core**
- **Framework**: [Next.js 14](https://nextjs.org/) (App Router & React Server Components)
- **Language**: [TypeScript](https://www.typescriptlang.org/) (Strict Mode)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) (Scroll-driven Parallax & Organic Spring Inertia)
- **Icons**: [Lucide React](https://lucide.dev/)

### **Backend & Systems**
- **Runtime**: Node.js & Next.js Edge API Routes
- **Databases & Cache**: PostgreSQL / Firebase
- **Tooling**: Git, Postman, n8n Automation, Google Antigravity IDE

## 🚀 Key Features

1. **Editorial Dark Aesthetic**: High-contrast, typography-driven layout with frosted glassmorphic navigation (`backdrop-blur-2xl`).
2. **Scroll-Driven 3D Background Engine**: GPU-accelerated planetary physics system with luminous neon torus rings, glowing molten amber spheres, and obsidian satellite pearls responding to user scroll inertia.
3. **Interactive Case Studies Showcase**: 6 live production web applications featuring direct inspection modals, performance metrics, and outbound links.
4. **Developer Profile & Principles**: Transparent architectural philosophy, categorized tech stack breakdown, and direct consultation booking.
5. **SEO & Performance Optimized**: Sub-second First Contentful Paint (FCP), semantic HTML5 tags, and 100% responsive viewport layouts.

## 💻 Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/Prahashya-08/portfoliorui.git
cd portfoliorui
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 4. Build for production
```bash
npm run build
npm run start
```
